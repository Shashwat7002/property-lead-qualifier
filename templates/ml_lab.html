What do these metrics mean?

MAE is the average absolute dollar error. RMSE penalizes large mistakes more. R² compares squared error with predicting the test-set average: 1 is perfect, 0 matches that reference, and a negative value is worse.

The bootstrap resamples test-house errors to estimate sampling uncertainty. It does not capture every source of uncertainty, such as retraining the model or a different housing market.

Confidence interval ≠ prediction interval

The 95% interval describes uncertainty in a model’s average error. The 90% prediction interval is a range for a future sale price, calibrated on separate houses.

90% is a long-run coverage target for similar data, not a guarantee for an individual house.

02 / MISSING DATA

An empty field is still information.

Real property records have gaps. Here, missing numeric features are filled with the training-set median. The model also receives missingness indicators, so it can distinguish an observed value from a filled-in one.

THE IMPORTANT DETAIL

Medians and scaling are learned from training data only. Looking at test data while preparing the features would leak information into the evaluation.

Missingness across the dataset; replacement values learned from the training split.

A blank is not automatically zero. A missing frontage measurement is unknown; a recorded garage area of zero can be a real value. Median imputation is a simple baseline, and can miss why information is absent.

      04 / HOW IT WORKS

      Small model. Visible decisions.

      01

      Learn a relationship

      Each house is a row. Its features are the inputs; its sale price is the target. Ridge regression combines weighted features into a numeric prediction, with a penalty that keeps coefficients from growing too large.

      02

      Keep the test honest

      A pipeline fills missing values, adds indicators, scales features, and trains the model. Only the training split fits these steps. The final test split stays separate until evaluation.

      03

      Measure uncertainty

      Calibration houses set the conformal interval width from prediction errors. Test houses then measure actual coverage. Bootstrap resampling estimates a confidence interval around the test-set average error.

      What this experiment can’t establish

      This is an educational, linear model of historical transactions. It can miss nonlinear relationships, neighborhood effects, unusual homes, and changes over time. Randomly splitting historical sales does not simulate predicting a later housing market. Conformal coverage relies on calibration and future examples being exchangeable; market shifts can break that assumption. A feature’s learned weight is an association, not proof of causation.
